# Z镇

> ***“欢迎来到Z镇，这里不只是地图上的一个坐标，更是每一位伙伴可以安心落脚的家。”***

## 社团简介

Z镇是Friend-友谊服务器中一个以**自由、协作、共创**为理念的玩家社团。这里既有温馨的日常互助，也有共同建设的宏大蓝图——无论你钟情于建造、探索还是经营，都能在Z镇找到属于自己的位置。

我们相信，一个社团的温暖，来自每一位成员的付出与真心。Z镇的大门始终敞开，欢迎志同道合的伙伴加入，一起把这片土地经营得越来越好。

## 宗旨

- **自由开放**：尊重每位成员的玩法选择，不强制、不束缚；
- **团结互助**：守望相助，共建共享，让家更像家；
- **共创共赢**：鼓励成员发挥所长，共同推动社团成长。
